About This Project

The Problem

Congressional committee hearings are a vital part of the legislative process, yet official transcripts can take a year or more to be published by Congress. Private transcription services exist, but they charge fees that put this public information behind a paywall.

This creates a significant transparency gap: by the time official transcripts are available, the policy discussions they document may no longer be timely or relevant to current debates.

Our Solution

This site uses AI speech recognition technology to automatically generate transcripts from committee hearing video streams, typically within hours of a hearing taking place. These transcripts are then published here for free public access.

How It Works

  1. Discovery: We monitor the Congress.gov API for new committee meetings with available video.
  2. Audio Extraction: Audio is extracted from official committee video streams hosted on YouTube and Senate committee websites.
  3. Transcription: The audio is processed using OpenAI's Whisper speech recognition model to produce timestamped transcripts.
  4. Key Excerpts: Substantive passages are automatically extracted from each hearing to help users quickly assess relevance.
  5. Publication: Transcripts are published to this website, with EPUB versions available for download and offline reading.

Important Disclaimers

  • These transcripts are auto-generated and may contain errors, particularly with proper names, technical terms, and crosstalk.
  • They should not be cited as official records. For official transcripts, see the Government Publishing Office.
  • These transcripts do not include speaker identification. All text is presented as a continuous transcript without attribution to individual speakers.

Data Sources

  • Congress.gov API — Hearing metadata, committee information, witness lists
  • Committee YouTube channels — House committee hearing video
  • Senate ISVP — Senate committee hearing video
  • Senate Committee Hearings Database — Senate hearing discovery

Open Source

This project demonstrates the potential for AI to make government more transparent and accessible. The transcription pipeline is open source and can be run by anyone to process additional hearings.

Source code: GitHub Repository

Limitations

  • Transcripts are generated using OpenAI Whisper (base.en model). Accuracy improves with larger models but processing time increases significantly.
  • Proper nouns (names of members, witnesses, locations) are particularly prone to transcription errors.
  • The system currently does not distinguish between speakers. All speech is rendered as continuous text without attribution.
  • Coverage is not yet comprehensive. New hearings are added as they become available, prioritizing high-profile committees.
